# Дети — прототип игрового раздела

Интерактивный прототип раздела **«Играть»** для детского режима онлайн-кинотеатра.
Ориентирован на **телефон** (портрет), тёмная тема.

## Что внутри

| Путь | Описание |
|------|----------|
| `index.html` | Главная (Лента) с таббаром |
| `games/index.html` | Хаб игр, открывается табом «Игры» |
| `assets/home/` | Баннер и постеры, вырезанные из макета |
| `assets/Иконки/` | Иконки таббара |
| `games/coloring/` | Раскраска: крокодил и лев |
| `assets/coloring/` | Исходные контурные картинки |
| `css/` | Стили хаба и раскраски |
| `js/coloring.js` | Заливка замкнутых областей |

## Как открыть

1. Откройте `index.html` в браузере (Safari / Chrome на планшете удобнее всего).
2. Или поднимите локальный сервер из этой папки:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Возможности раскраски (v1)

- Две векторные раскраски: крокодил и лев (`assets/coloring/*.svg`)
- Заливка отдельных контуров по нажатию
- 12 цветов, ластик, сброс, кнопка «Готово»
- Тёмная тема, вёрстка под телефон: картинка сверху, палитра снизу
